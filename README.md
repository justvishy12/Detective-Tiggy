# Detective TIggy

Detective Tiggy is an interactive 2D point and click game where you solve mysteries in Tiggy's house, and fix items here and there,
while finding out who is creating all the trouble..
(It is really recommended to read the guide in the game before starting)

Specials:
- Dialogue/Skip Text
- Different Minigames
- Cool Characters, and Rooms
- Interactive Items

How To Play:
- Available On Browser
- Hosted on Itch.io
  
Controls:
- Mouse - Click
- Space bar - Skip text
- Esc to access settings menu

Credits:
- SFX created by me
- Assets created in Figma
- Made in Godot 4.7

Good luck fellow detectives, and solve that mystery!
